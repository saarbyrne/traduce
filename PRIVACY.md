# Traduce privacy policy

Last updated 24 September 2026.

## Data

Traduce does not collect, store or sell personal data. It has no account, no analytics and no server of its own.

## Translation

When you ask for a translation, only the selected text is used.

- If your browser has its built-in translation model, the text is translated on your device and is not sent anywhere.
- Otherwise the text is sent over HTTPS to MyMemory (https://mymemory.translated.net), run by Translated S.r.l., which returns the translation. MyMemory's own terms apply to that request.

Traduce keeps recent translations in memory while the browser is open, so the same text is not sent twice. They are cleared when the browser closes.

## Settings

The on/off setting for the floating button is saved with Chrome sync storage. It contains no text you translated.

## Page access

Traduce runs on every page so it can show its button when you select text. It reads the page only when you select text, and it does not read or send anything else.
